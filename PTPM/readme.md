#### 1. Выбор программ
Я выбрал эти, так как имел с ними дело и считаю их полезными:

- **LibreOffice**

- **HandBrake**

- **GitHub**

#### 2. Описание приложений

#### LibreOffice

- Свободный офисный пакет для создания электронных таблиц, документов, презентаций. Доступен на всех платформах, которые я использую

- Целевая аудитория: студенты, офисные работники, преподаватели и начинающие пользователи.

- Платформы: Windows, Linux (MacOS, Android).

#### HandBrake

- Свободный видеоконвертер формата файла, кодека, да и просто может сжимать размер видео.

- Целевая аудитория: профессиональные видеоредакторы, создатели контента.

- Платформы: Windows, Linux (MacOS).

#### GitHub

- Бесплатный веб-сервис для хостинга IT-проектов и их совместной разработки, доступен не только в интернете, но и в гибридном приложении.

- Целевая аудитория: программисты, разработчики ПО.

- Платформы: Web (github.com), Android, iOS, Windows (GitHub Desktop).

#### 3. Анализ пользовательского интерфейса

- **Навигация** 
  - LibreOffice содержит "навигатор" в котором можно просмотреть недавние документы или создать новые, используя предложенные редакторы офисного пакета.
  
  - HandBrake имеет классическую навигационную панель, с выбором файла, настройками и прочим. Есть ещё одна панель для навигации в настройках конвертации, сжатия.
  
  - GitHub в мобильной версии навигационная панель находится снизу, можно увидеть свой профиль "Profile", посмотреть репы, которые в тренде "Explore", уведомления "Notificaions", и свои звёздочки, проекты, запросы на пулл и т.д. в "Home" в веб версии навигация зависит также и от браузера, но главное что там больше возможностей чем в мобильной версии.
  
  В целом они все лёгкие в навигации и логичные.
  
- **Визуальный дизайн** 

   - LibreOffice во многом повторяет проприетарные редакторы от Microsoft (Что является плюсом для новичков этого софта), при этом не совсем уж "копируя". Внешний вид в Linux во многом зависит от темы графической оболочки, из-за чего могут возникнуть графические артефакты, неудобства. В Windows и Android дизайн стандартизирован и на этих платформах он выглядит старомодно, но зато им удобно пользоваться и интерфейс не разрушается.
   - HandBrake также зависит от темы в Linux, но интерфейс не так сильно деформируется, выглядит крепким, солидным. На Windows он выглядит как старенькая программка по стандартам Windows 7, ничего особенного. Мне больше всего понравился его значок с ананасом и коктейлем. Для создателей контента удобно видеть прогрессбар и fps (скорость обработки кадров) наверно. 
   - GitHub имеет прекрасный, независимый дизайн, преображает код, markdown и простой текст, не говоря уже про интерфейс. Я вообще под него подстраиваюсь и пишу этот .md файл в Typora с выбранной темой "GitHub Night". Даже не знаю что добавить.
   
- **Интерактивность**
  
- Справка? Конкретика? перефразировать
  
  - LibreOffice реагирует без задержек, но мне не нравится что выбранный раздел навигационной панели редактора перекрывает другие разделы на панели,
  ![снимок1](covering.png)
  в других программах такого не происхоит, т.к. обычно окошки открываются ниже панели.
  - HandBrake предлагает выбрать preset с нужным форматом конвертации видео, например "Creator 1080p60" идеально подходит для сжатия видео, которое будет проигрываться из сети (видеохостинга), остаётся только нажать на "Start", подождать пока ЦП всё перекодит и сжатое видео готово.
  - На сайте GitHub можно просто создать репозиторий и с помощью расширения для Visual Studio Code сразу клонировать его в окно редактора буквально в три кнопки. Однако в мобильной версии возможности ограничены, там можно отредактировать файлы, но создать репозиторий, сделать его публичным или скрыть не получится и мобильная версия чаще используется как аутентификатор подозрительных действий в веб-версии.
  
- **Пользовательский опыт:**

  - В общем, все 3 эти программы мне нравятся, обогащают народное сообщество open-source, очень полезны для меня и огромного количества людей, хоть и ко всем можно найти альтернативу.
#### 4. Выявление недостатков
- LibreOffice: перекрытие панелей навигации окнами от самой же навигации, низкое разрешение интерфейса или неправильное отображение на разных графических оболочках или темах Linux.
- HandBrake: престарелый дизайн, непонятные мне функции (ну это my bad).
- GitHub: я посидел в веб-версии прежде чем, что-то тут писать и понял что претензий к дизайну и интерфейсу не будет, Desktop-версия не так дружелюбно выглядит и ограничение функционала мобилы.
#### 5. Предложения по улучшению
- LibreOffice: сделать более удобный интерфейс и начать реализацию облачного офиса, как это сделали Microsoft.
- HandBrake: сделать сохранения профилей, как это реализовано во многих программах сферы медиа.
- GitHub: сделать Web IDE, чтобы можно было редактировать файлы из браузера, такая функция реализована в GitLab и я считаю это удобным.
