## 1. Выбор программ

Я выбрал эти, так как имел с ними дело и считаю их полезными:

- **LibreOffice** — офисный пакет для работы с документами, таблицами и презентациями.

- **HandBrake** — видеоконвертер для преобразования и сжатия видеофайлов.

- **GitHub** — платформа для хостинга IT-проектов и совместной разработки.
---
## 2. Описание приложений

### **LibreOffice**
- **Назначение**: Свободный офисный пакет для создания и редактирования текстовых документов, электронных таблиц, презентаций и других форматов.
- **Целевая аудитория**: 
  - Студенты и преподаватели.
  - Офисные работники.
  - Пользователи, ищущие бесплатную альтернативу Microsoft Office.
- **Платформы**: Windows, Linux, macOS, Android.

### **HandBrake**
- **Назначение**: Видеоконвертер для преобразования форматов видео, изменения кодеков и сжатия файлов.
- **Целевая аудитория**: 
  - Профессиональные видеоредакторы.
  - Создатели контента для YouTube и других платформ.
  - Пользователи, которым нужно оптимизировать видео для хранения или загрузки.
- **Платформы**: Windows, Linux, macOS.

### **GitHub**
- **Назначение**: Веб-сервис для хостинга IT-проектов, совместной разработки и управления версиями кода.
- **Целевая аудитория**: 
  - Программисты и разработчики ПО.
  - Команды, работающие над open-source проектами.
  - Студенты и преподаватели, изучающие программирование.
- **Платформы**: Веб-версия (github.com), GitHub Desktop (Windows, macOS), мобильные приложения (Android, iOS).

## 3. Анализ пользовательского интерфейса

### **Навигация**
- **LibreOffice**: 
  - Навигация реализована через "Навигатор", который позволяет быстро переключаться между документами и создавать новые файлы. Однако панель редактора перекрывается открывшимся меню, что может вызывать неудобства.
  - Пример: При открытии нескольких документов вкладки на панели навигации становятся слишком узкими, что затрудняет выбор нужного файла.

- **HandBrake**: 
  - Интерфейс разделен на две основные панели: для выбора файла и для настройки параметров конвертации. Навигация интуитивно понятна, но отсутствие подсказок для некоторых функций может затруднить использование новичками.
  - Пример: Пользователь может легко выбрать пресет "Fast 1080p30", но для тонкой настройки параметров кодирования потребуется изучить документацию.

- **GitHub**: 
  - В веб-версии навигация реализована через верхнюю панель, которая позволяет быстро переключаться между репозиториями, уведомлениями и профилем. В мобильной версии навигационная панель расположена внизу, что упрощает использование на небольших экранах, но в мобильной версии отсутствует возможность создания новых репозиториев, что ограничивает функциональность.

### **Визуальный дизайн**
- **LibreOffice**: 
  - Интерфейс напоминает Microsoft Office, что упрощает переход для пользователей, привыкших к проприетарным решениям. Однако в Linux внешний вид может зависеть от темы графической оболочки, что иногда приводит к визуальным артефактам.
  - Пример: На некоторых дистрибутивах Linux кнопки на панели инструментов могут отображаться некорректно.

- **HandBrake**: 
  - Дизайн интерфейса минималистичен и функционален, но выглядит устаревшим, особенно на Windows. В Linux интерфейс более стабилен, но также не отличается современным видом.
  - Пример: Прогресс-бар и отображение FPS (скорость обработки кадров) полезны для пользователей, но общий дизайн не привлекателен.

- **GitHub**: 
  - Дизайн веб-версии современный и минималистичный, с поддержкой тем (светлая и темная). Интерфейс GitHub Desktop выглядит менее проработанным, но остается функциональным.
  - Пример: Подсветка синтаксиса и предпросмотр Markdown-файлов делают работу с кодом удобной и приятной.

### **Интерактивность**
- **LibreOffice**: 
  - Интерфейс реагирует на действия пользователя без задержек, но перекрытие панелей навигации окнами редактора может вызывать неудобства.
  - Пример: При открытии нескольких документов вкладки на панели навигации становятся слишком узкими, что затрудняет выбор нужного файла.

- **HandBrake**: 
  - Интерфейс прост и понятен, но отсутствие подсказок для некоторых функций может затруднить использование новичками.
  - Пример: Пользователь может легко выбрать пресет "Fast 1080p30", но для тонкой настройки параметров кодирования потребуется изучить документацию.

- **GitHub**: 
  - Веб-версия предлагает высокий уровень интерактивности, включая интеграцию с IDE (например, Visual Studio Code). Мобильная версия ограничена в функциональности.
  - Пример: В мобильной версии отсутствует возможность создания новых репозиториев, что ограничивает функциональность.

### **Пользовательский опыт**
- **LibreOffice**: 
  - Удобен для базовых задач, но требует доработки интерфейса для повышения удобства использования.
- **HandBrake**: 
  - Прост в использовании для базовых задач, но требует улучшения дизайна и добавления подсказок.
- **GitHub**: 
  - Веб-версия предлагает отличный пользовательский опыт, но мобильная и Desktop-версии нуждаются в доработке.

## 4. Выявление недостатков

### **LibreOffice**
- Сложности навигации от перекрытия панелей
- Низкое разрешение интерфейса на некоторых версиях приложения для Linux.
- Устаревший дизайн на Windows и Android.

### **HandBrake**
- Устаревший визуальный дизайн.
- Отсутствие подсказок для сложных функций.

### **GitHub**
- Ограниченная функциональность мобильной версии.
- Менее удобный интерфейс GitHub Desktop по сравнению с веб-версией.
