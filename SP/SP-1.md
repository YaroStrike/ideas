# Роль веб-технологий в современном мире
**Веб-технологии** - это набор инструментов, протоколов и языков, которые используются для создания, управления и взаимодействия с веб-приложениями и сайтами.

**Основные компоненты**: (HTML, CSS, JavaScript). Серверные языки: (PHP, Python, Ruby). Базы данных и протоколы передачи данных.

### Влияние веб-технологий на общество:

#### Экономика
Банки, крипта, блокчейн токены

#### Развлечения
Медиа-платформы, стриминговые, казино

#### Гос. услуги
Цифровые документы, электронное правительство, онлайн голосование

#### Тренды
Progressive web apps -  веб-приложения, работающие как гибридные.
Single page app - страница, которая загружается без загрузки.
Web assembly - продвинутые приложения в браузере.

### PHP как ключевой back-end инструмент
PHP - серверный язык программирования, который используется для создания динамических веб-страниц. PHP выполняется на сервере, а результат его работы отправляется в браузер.

**Преимущества PHP**:
широкая поддержка хостинга
интеграция БД
большое количество готовых решений

**Основные возможности PHP**:
Обработка форм, работа с БД, создание API, управление сессиями и cookie. Интеграция с внешними серверами
